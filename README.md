# Chief of Staff

A personal operating system for one physician-technologist: voice-first, local-first, multi-agent.

This repo is curated from the working Voice Hub bundle and Notification Agent artifacts produced in the Reputation Engine project. It collects the runnable pieces (wake-word model, on-device STT/TTS wiring, agent dispatch and observability layer, calendar/email integrations) into a single buildable surface.
